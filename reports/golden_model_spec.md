# SpikeNav golden model — fixed-point arithmetic specification

Bit-exact reference: `golden_c/snn_golden.c` (C99) == `snnsim/engine.py` with `arith='fixed'`
(checked by `tests/test_golden_c.py`). Network: VPRSNN test-mode module (784 inputs, 400 E, 400 I;
https://github.com/QVPR/VPRSNN, MIT License). This file is generated by `scripts/write_spec.py`.

## 1. Number formats

| Quantity | Storage | LSB (real value) | Range / saturation |
|---|---|---|---|
| membrane potential v (E and I) | signed int32 (25 bits used) | 2^-16 mV | saturate to [-16777216, 16777215] = ±256 mV |
| conductances ge_E, gi_E, ge_I | unsigned, int32 (23 bits used) | 1/4080 (= 1/(255·16)) | saturate to [0, 8388607] (≈2056) |
| input weight (8-bit) | uint8 code c | w = c/255 | increment ge by c·16 (exact) |
| input weight (4-bit) | uint4 code c | w = c/15 | increment ge by c·272 (exact) |
| E firing threshold THR[j] | signed int32 per neuron | 2^-16 mV | THR = floor((θ_j[mV] − 72)·2^16 + 0.5) |
| refractory / timer counters | unsigned, saturating | 1 step | any cap ≥ T_LOCK gives identical results (10 bits suffice at dt = 0.1 ms) |
| delay-ring accumulators | signed int64 in the model; ≤ 24 bits needed (see ranges) | 1/4080 | — |

Helper operations (all integer): `asr(x,s)` = arithmetic shift right (floor division by 2^s);
`rshr(x,s) = asr(x + 2^(s-1), s)` (round half up). Products are formed in 64-bit.

## 2. One integration step (Brian2 schedule; all updates of phase 1 use the old state)

```
Phase 1 — neuron update, for every neuron j:
  since_e[j]++, since_i[j]++, timer[j]++                 (saturating)
  nre = since_e[j] >= REF_E ;  nri = since_i[j] >= REF_I
  E: if nre:
       C   = gi_E * asr(E_INH - v_E, 7) - ge_E * asr(v_E, 7)
       acc = KV_E * (V_REST_E - v_E) + KC_E * C
       v_E = sat(v_E + rshr(acc, 30))
     ge_E = asr(ge_E * DGE, 16) ;  gi_E = asr(gi_E * DGI, 16)
  I: if nri:
       acc = KV_I * (V_REST_I - v_I) - KC_I * (ge_I * asr(v_I, 7))
       v_I = sat(v_I + rshr(acc, 30))
     ge_I = asr(ge_I * DGE, 16)
Phase 2 — thresholds (on the updated values):
  sI[j] = (v_I > V_TH_I) and nri
  sE[j] = (v_E > THR[j]) and (timer[j] >= T_LOCK) and nre
  input spikes of this step from the spike generator (Section 4)
Phase 3 — synapses:
  for each input spike i, for each j: ring[slot(i,j)][j] += INC[i][j]
      slot = (t + d[i][j]) mod S                         (0.1 ms or 1 ms-multiple delays)
      slot = ((t div SPM) + 1 + d_ms[i][j]) * SPM mod S  (1 ms binned delivery, proposed HW)
  ge_E[j] = min(ge_E[j] + ring[t mod S][j], G_MAX) ; ring[t mod S][j] = 0
  ge_I[j] = min(ge_I[j] + W_EI * sE[j], G_MAX)                       (E->I one-to-one)
  gi_E[j] = min(gi_E[j] + W_IE * (N_I - sI[j]), G_MAX), N_I = sum_j sI[j]  (I->E all-but-self)
Phase 4 — resets: if sE[j]: v_E = V_RESET_E, timer = 0, since_e = 0, count[j]++
                  if sI[j]: v_I = V_RESET_I, since_i = 0
t = t + 1
```

Hard reset at the start of every module run (proposed hardware): v_E = V_REST_E, v_I = V_REST_I,
all conductances 0, all counters saturated (neurons immediately eligible), ring buffer cleared, t = 0.
A module run is n_present = 350 ms / dt steps of input; the output is count[j] over those steps.
(Reference carry-over mode instead starts with v = V_INIT, timer = 0, a 0.5 s rest, and 150 ms rests.)

simulated time; with float64 accumulation the first step that satisfies it is k = 501 at dt = 0.1 ms.

## 4. Hash and spike generator (multiplier-free except the final range reduction)

```
mix32(h): h += h<<10; h ^= h>>6; h += h<<3; h ^= h>>11; h += h<<15     (mod 2^32)
delay hash: h = mix32(mix32(((i<<9) | j) XOR module_seed)) ; h16 = h >> 16
  0.1 ms delays : d = (h16 * (MAXD+1)) >> 16, MAXD = 10 ms/dt   (101 values at dt=0.1 ms)
  1 ms delays   : d_ms = (h16 * 11) >> 16 (0..10 ms); multiply by 11 = (x<<3)+(x<<1)+x
spike generator: 16 xorshift32 generators (x^=x<<13; x^=x>>17; x^=x<<5)
  generator g serves pixels g, g+16, ..., g+16*48 in that order, one draw per pixel per step
  seed_g = mix32(mix32(stream*16 + g) XOR 0xA5A5A5A5), forced to 1 if zero
  stream = (poisson_seed<<26) | (session<<24) | (module<<16) | query   (module = 255: shared train)
  spike(pixel i) = (x >> 8) < THRP[i],  THRP[i] = floor(pixel_i/4 * dt * 2^24 + 0.5)
```

## 6. Operand widths for an RTL implementation

- asr(v, 7) is an 18-bit signed operand (|v| < 256 mV); diff = asr(E_INH − v, 7) likewise.
- ge/gi operands: width set by the measured maxima above (ge_E, ge_I, gi_E); gi_E peaks are the widest.
- KV_*, KC_* fit in 24 bits; products C (≤ ~41 bits) × KC (≤ 19 bits) need a 64-bit (or 2×DSP cascaded) accumulator.
- Multiplies per neuron-step: E = 6 (gi·diff, ge·vq, KV·(Vr−v), KC·C, ge·DGE, gi·DGI); I = 4 (ge·vq, KC·(..), KV·(Vr−v), ge·DGE).
  DGE/DGI multiplies are by constants and may be replaced by shift-add networks in RTL only if bit-exactness
  with this specification is preserved (i.e. compute exactly g·DGE).
